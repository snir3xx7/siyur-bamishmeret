# מעקב חניכים – התקנה (פעם אחת, כ־5 דקות)

המעקב שולח לגיליון Google **פרטי שלכם** את מי שנכנס, אילו תרחישים התחיל וסיים, הציון והמשוב. בעמוד **„ניהול”** באתר רואים הכול – מוגן בסיסמה שרק אתם יודעים. הסיסמה נבדקת בגיליון ולא נשמרת באתר.

## שלבים

1. **גיליון חדש** – ב־Google Sheets (בחשבון ה־Gmail שלכם): גיליון ריק חדש, למשל „סיור במשמרת – מעקב”.
2. **סקריפט** – בתפריט: **הרחבות → Apps Script**. מוחקים את מה שיש ומדביקים את כל התוכן של `Code.gs` (בתיקייה הזו). שמירה (💾).
3. **סיסמה וצוותים** – בצד שמאל: **⚙ הגדרות הפרויקט** → למטה **מאפייני סקריפט** → **הוספת מאפיין**:
   - `ADMIN_PASSWORD` – הסיסמה שלכם (לפחות 10 תווים, לא סיסמה שאתם משתמשים בה במקום אחר).
   - `TEAMS` – הקורסים/הצוותים מופרדים בפסיקים, למשל: `קורס סיור 12, קורס סיור 13`
4. **פריסה** – למעלה: **פריסה → פריסה חדשה** → ⚙ סוג: **אפליקציית אינטרנט**:
   - ביצוע בתור: **אני**
   - למי יש גישה: **כל אחד**
   - **פריסה** → Google יבקש לאשר הרשאות לגיליון שלכם → מאשרים.
5. **הכתובת** – מעתיקים את **כתובת אפליקציית האינטרנט** (מסתיימת ב־`/exec`) ושולחים למפתח. היא נכנסת ל־`src/config/tracking.ts`, והמעקב נדלק באתר.

## מה רואים

- **בגיליון** (לשונית `Events`): שורה לכל אירוע – זמן, חניך, צוות, סוג אירוע, תרחיש, ציון, סוג סיום, תחומים ומשוב לשיפור.
- **באתר → למדריך → כניסה לניהול**: טבלת חניכים (כניסות, התחיל, השלים, תרחישים שונים, סיום טוב, ממוצע), פירוט לכל חניך עם המשוב של כל סבב, תחומים לחיזוק, משוב שחוזר ולפי תרחיש. סינון לפי קורס/צוות.

## פרטיות ואבטחה

- נשלחים רק: שם, קורס/צוות, מזהה מכשיר אקראי, ותוצאות התרחישים. **לא** נשלח מה שהחניך כתב בפנקס, ולא מספר זהות.
- החניך רואה הודעה על כך במסך הכניסה.
- הסיסמה נבדקת בסקריפט; אחרי 8 ניסיונות שגויים הכניסה ננעלת לרבע שעה.
- מי שיודע את כתובת הסקריפט יכול לשלוח אליו שורות (לא לקרוא). אם יש חשש – מוחקים שורות בגיליון, או פורסים מחדש לכתובת חדשה.
- כדי לעצור את המעקב: מוחקים את הכתובת מ־`src/config/tracking.ts` (או מבטלים את הפריסה ב־Apps Script).

## עדכון הסקריפט

אחרי הדבקת גרסה חדשה של `Code.gs`: **פריסה → ניהול פריסות → ✏️ → גרסה: חדשה → פריסה**. הכתובת נשארת אותה כתובת.
