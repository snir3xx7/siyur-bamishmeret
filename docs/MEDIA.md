# רשימת נכסי מדיה

כל הנכסים בפרויקט **מקוריים** ונוצרו במסגרת הפרויקט (ללא דגימות, תמונות או קטעי קול חיצוניים), ומופצים יחד עם קוד הפרויקט ותחת אותו רישיון.

- **איורים חצי־ריאליסטיים** (רקעים, דמויות, רכבים): נוצרו מקומית במחשב הפיתוח עם ComfyUI ומודל **FLUX.1 [schnell]** של Black Forest Labs (רישיון Apache-2.0, שמתיר שימוש בתוצרים לכל מטרה). ההנחיות, הזרעים וההגדרות ב־`scripts/ai-art/art.json`; הפקה מחדש: `npm run art` (דורש ComfyUI פעיל). כל הדמויות והמקומות בדויים; אין סמלים של גופים אמיתיים. השלטים בעברית אינם חלק מהציור – הם שכבת טקסט בזירה (`kind: "sign"`).
- **צלילים, אייקונים וציורי גיבוי וקטוריים**: נוצרים בקוד – `npm run assets` (דורש `ffmpeg`).

## קריינות – מה חסר ואיפה מוסיפים

אין כרגע קריינות מוקלטת בעברית באף תרחיש. כל ההודעות מוצגות כתמליל מלא, ואפשר להפעיל בהגדרות הקראה בקול הדפדפן אם קיים קול עברי במכשיר.

| תרחיש | קריינות חסרה | תיקייה מומלצת |
|---|---|---|
| תאונת דרכים קלה בגשם | הודעת המוקד, תגובות המוקד, דיאלוגים | `public/audio/voice/accident-rain/` |
| רעש בבניין מגורים | הודעת המוקד, דיאלוגים | `public/audio/voice/noise-building/` |
| ויכוח בחצר משותפת | הודעת המוקד, דיאלוגים | `public/audio/voice/yard-dispute/` |

הוספה: שמרו קובץ MP3 (למשל `dispatch.mp3`), מפו אותו בשדה `media.voice` של התרחיש – המפתח `dispatch` להודעת הפתיחה או מזהה בחירה (למשל `"o-feel": "audio/voice/accident-rain/o-feel.mp3"`) – והוסיפו שורה לטבלה למעלה עם מקור, רישיון ושם הקריין/ית. קובץ שהוגדר מושמע במקום הקראת הדפדפן.
