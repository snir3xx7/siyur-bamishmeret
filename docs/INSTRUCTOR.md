# מדריך למדריך

## הפעלה בכיתה

1. פתחו את עמוד **„למדריך”** במשחק, בחרו תרחיש וזרע, והעתיקו את **הקישור לגרסה קבועה**. כל מי שפותח אותו מקבל את אותן נסיבות (למשל איזה נהג נפגע, מאיזו דירה מגיע הרעש).
2. החניכים בוחרים משמרת, רמת קושי ומצב:
   - **למידה** – אפשר להשהות ולבקש רמזים.
   - **תרגול עצמאי** – אין רמזים; המשוב מוצג בסיום.
3. בסיום: ציון מתוך 100, נקודות לשימור ולשיפור, ציר החלטות וטיוטת דוח פעולה.
4. **מצב מקרן** בתחקיר מגדיל את הטקסט. כל שורה בציר ההחלטות נפתחת ומציגה מה החניך ידע, מה בחר, מה קרה וכמה נקודות קיבל. הכפתור **„פתיחה מחדש מנקודה זו”** משחזר את המשחק לרגע שלפני ההחלטה, במצב למידה, כדי לדון בחלופות.
5. ייצוא: העתקת משוב, הורדת קובץ טקסט (תחקיר + דוח), והדפסה או שמירה כ־PDF דרך הדפדפן.

## לוח תוצאות הכיתה

אין שרת, והתוצאות לא נשלחות לשום מקום מעצמן.

1. בסוף כל תרחיש החניך כותב את שמו בכרטיס **„שליחת התוצאה למדריך”** ולוחץ **„העתקת קוד תוצאה”** (או מוריד קובץ), ושולח לכם בוואטסאפ או במייל.
2. בעמוד **„למדריך”** → **„לוח תוצאות הכיתה”**: מדביקים את הקודים, כמה יחד ואפילו הודעות שלמות, או טוענים קבצים.
3. מקבלים: ממוצע כיתה, תחומים לחיזוק מהחלש לחזק, נקודות לשיפור שחוזרות, טבלה לפי תרחיש ולפי חניך, וייצוא ל־CSV לאקסל.

הקוד כולל רק שם, תרחיש, ציונים לפי תחום ונקודות לשיפור, בלי הפנקס ובלי טקסט חופשי. הלוח נשמר רק בדפדפן של המדריך.

## עורך תרחישים (בלי קוד)

בעמוד „למדריך” → **„פתיחת העורך”**:

1. בוחרים תרחיש קיים ולוחצים **„יצירת עותק לעריכה”**.
2. עורכים כל טקסט: שמות ותפקידים, מקום, קריאת המוקד, שורות הדמויות, הבחירות, הרמזים והמשוב. המבנה (מה כל בחירה עושה, מתי נפתחות פעולות) נשאר כמו במקור, כך שהתרחיש נשאר תקין.
3. **„בדיקת תקינות”**, ואחר כך **„▶ לנסות את התרחיש”**. העותק מופיע בקטלוג תחת „התרחישים שלי”.
4. לשיתוף עם מדריכים אחרים: **„ייצוא לקובץ”**, ואצלם **„טעינת קובץ תרחיש”**.

שורה שנערכה מאבדת את ההקלטה המקורית ומוקראת בקול הדפדפן (אם הופעל בהגדרות). העותקים נשמרים בדפדפן בלבד.

## מצב „מצא את הטעויות”

בכרטיס כל תרחיש: **„🔎 מצא את הטעויות”**. החניך צופה בטיפול של צוות אחר, צעד אחרי צעד, ומסמן בכל צעד „תקין” או „טעות”, עם הסבר מיד. בסוף: כמה טעויות זוהו ומה הצוות בכלל לא עשה. כל לחיצה על „טיפול אחר” יוצרת מסלול חדש, ומתאים לדיון בכיתה על המקרן.

## שכפול תרחיש – דוגמה מקצה לקצה

נשכפל את „תאונת דרכים קלה בגשם” לתרחיש חדש: **תאונה בחניון סופרמרקט**.

1. **העתקה**
   ```bash
   cp public/scenarios/accident-rain.json public/scenarios/accident-parking.json
   ```
2. **זהות התרחיש** – בקובץ החדש:
   ```json
   "id": "accident-parking",
   "version": 1,
   "title": "תאונה קלה בחניון",
   "location": { "name": "חניון מרכז הדקל", "area": "קריית אלון (בדוי)" },
   ```
3. **קטלוג** – הוסיפו רשומה ל־`public/scenarios/index.json` (אותם `id`, `version`, `title`, `category`, `summary`, `estimatedMinutes`, `difficultyLabel`, `skills`, `shifts`, ו־`"file": "accident-parking.json"`).
4. **הודעת המוקד** – שנו את `dispatch.lines` ואת `dispatch.time` לכל משמרת.
5. **דיאלוגים** – ערכו `lines` בכל בחירה. דוגמה – שינוי תגובת הנהגת:
   ```json
   { "speaker": "dana", "text": "נסעתי לאט, חיפשתי חנייה, והוא יצא ברוורס בלי להסתכל." }
   ```
   אם הטקסט מזכיר עובדה חדשה, הוסיפו אותה ל־`facts` וחשפו אותה ב־`effects.reveal`.
6. **מדיה** – רקע חדש: שמרו `public/img/parking-day.webp` ו־`parking-night.webp` (1600×900) ועדכנו `scene.background: "img/parking"` ואת `media.images`. צלילים: הוסיפו `public/audio/<שם>.mp3` ועדכנו `scene.ambience` ו־`media.audio`. רשמו כל נכס ב־`docs/MEDIA.md` עם מקור ורישיון.
7. **ניקוד** – התאימו את `scoring.rules`: עדכנו `explain`, `keep` ו־`improve` כך שיתארו את הפעולות בתרחיש החדש. הקפידו שכל משוב יתייחס לפעולה שבוצעה בפועל ולהשלכה שלה.
8. **מסלול מלא לבדיקה** – הוסיפו ל־`GOOD_PATHS` ב־`tests/unit/scenarios.test.ts` רצף פעולות שמגיע לסיום טוב ולציון 100.
9. **בדיקת כל המסלולים**
   ```bash
   npm test
   ```
   או בעמוד „למדריך” → „בדיקת כל המסלולים”. הבדיקה מדווחת על הפניות שבורות, מבויים סתומים, בחירות שאי אפשר להגיע אליהן וסיומים שלא הושגו.
10. **קישור קבוע** – אחרי פרסום, עמוד „למדריך” מפיק קישור `#/s/accident-parking?v=1&seed=…`.

## שינוי תרחיש קיים

- כל שינוי בתוכן או בניקוד ⇐ העלו את `version` בקובץ ובאינדקס. קישור עם גרסה ישנה יציג הודעה.
- משקלי תחומים: `scoring.weights`, למשל `{ "documentation": 15, "info": 20 }`. משקל 0 מסיר תחום. המשקלים מנורמלים ל־100.
- כל החניכים שמשחקים באותה גרסה מקבלים את אותם כללי ניקוד.

## תוכן נוהלי ומשפטי

המשוב בתרחישי ההשקה הוא משוב תרגולי כללי: תקשורת, הערכת מצב, תיאום ותיעוד. תוכן נוהלי או משפטי מחייב ייכנס **רק** אחרי שמדריך הזין מקור מאושר ובדק את נוסח המשוב. ציינו את המקור בתיאור התרחיש או בהערת שינוי במאגר.

## מה המשחק לא עושה

אין במשחק מכניקות נשק, תרחישי תקיפה או חיבור למערכות אמיתיות. כל הדמויות והמקומות בדויים. אפשר לבחור תחנה ואות קריאה אמיתיים (מחוז, תחנה וניידת) כדי שהקשר יישמע מוכר; קידומות שמסומנות „משוער” עדיין לא אומתו. אין במשחק סמלים או לוגו רשמיים של המשטרה.
